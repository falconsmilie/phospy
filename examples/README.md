# Public Examples

The active examples for the current public workflow are:

- `dataset_builder_demo.py`
- `kinase_workflow_demo.py`
- `signalome_workflow_demo.py`

`dataset_builder_demo.py` includes a concrete
`site_matrix.policy="build_from_metadata"` row-retention demonstration showing
that rows without usable `site_sequence` are excluded from that construction
path.

Historical scripts and fixture artifacts are kept under
`_archived_legacy/` for provenance only.
