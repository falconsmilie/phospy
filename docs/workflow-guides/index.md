# Workflow Overview

PhosPy supports one public workflow chain:

1. build `AnalysisReadyPhosphoDataset`
2. run `KinaseWorkflow`
3. optionally run `SignalomeWorkflow`

For most users, the quickstart already covers this path:

- [CLI Guide](../cli.md)
- [API Guide](../api.md)
