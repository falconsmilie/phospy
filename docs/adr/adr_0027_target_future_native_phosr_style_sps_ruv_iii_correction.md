## Decision

[ADR-0029: Native SPS/RUV-Style Batch Correction Prerequisites](adr_0029_native_sps_ruv_style_batch_correction_prerequisites.md).

ADR-0029 keeps the current support statement conservative: native SPS/RUV-style
batch correction is deferred until control-site representation, missing-value
policy, provenance, validation, and test prerequisites exist. This older record
is retained only for historical traceability.
