# Release Notes 1.5.0

Status: draft release notes for the `1.5.0` governance posture.

## Scientific Parity Highlights

- Core kinase scoring/prediction ranking parity is re-established on repaired
  comparison surfaces in the supported L6 lane.
- Ranking closure bars are enforced on explicit like-for-like contracts:
  `rewrite(stable)` vs `promoted_reference(stable)` for prediction-matrix
  ranking and ranked top-k export ranking.
- Cross-policy divergence (`stable` vs `r_parity`) remains separately reported
  and separately asserted; it is not used as a replacement for
  promoted-reference closure bars.
