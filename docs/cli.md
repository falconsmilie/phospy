# CLI Status

PhosPy workflow execution through a `phospy` command-line interface is not
currently supported.

Use the Python API instead. The [Quickstart](quickstart.md) shows the shortest
guided route from pandas tables to a result.

Continue with:

- [Quickstart](quickstart.md)
- [Public Python API](api/guide.md)
- [Build an Analysis-Ready Dataset](api/dataset-build-workflow.md)

For writing workflow outputs from Python, use the publisher helpers and bundle
services documented in [Output Bundles](output_bundles.md).
